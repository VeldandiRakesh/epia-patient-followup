# Screenshots Directory

This directory should contain application screenshots for documentation purposes.

## Recommended Screenshots

1. **dashboard.png** - Main dashboard with statistics
2. **patient-list.png** - Patient management list view
3. **ai-automation.png** - AI follow-up automation page
4. **patient-form.png** - Add/Edit patient form

## How to Add Screenshots

1. Navigate to the application at http://localhost:3000
2. Take screenshots of key pages
3. Save them as PNG files in this directory
4. Update the image references in the main README.md if filenames differ

## Note

Screenshots are optional for the assessment but recommended for documentation.
